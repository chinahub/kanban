## 已知限制（PRD §8.3，暂不处理）

- ~~数据源无连接池（每次 fetch 新建连接）~~ → 已收口（v1.9）：`DbConnectionPool` 按数据源 id 池化，指纹失配自动换池，借出 isValid 校验，单源并发上限 8
- 加密单密钥、无轮换
- fetch 仅单条 SELECT（v1.9 起由服务端守卫显式强制：非 SELECT/多语句直接 400；SQL 本身仍为看板作者整条编写，非参数化模板）
- AI 只读，不写回配置
- 历史记录仅 localStorage
- 协同编辑无 CRDT/OT 合并：在线可见 + 保存广播 + 手动「重新加载」兜底，并发保存后保存者胜（阶段 6 简化版决策）
- 蓝图条件表达式在主线程 `new Function` 求值（与过滤器 Web Worker 沙箱不同级），表达式由看板作者编写，信任级别同过滤器代码
