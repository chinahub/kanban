# G2 在 kanban 中的使用文档

> **版本**: v1.0
> **日期**: 2026-07-07
> **依赖**: `@antv/g2 ^5.4.8`
> **对应代码**: `kanban_web/src/components/ComponentRenderer.tsx`

---

## 1. 概述

本项目所有图表组件（10 类）统一由 `ComponentRenderer` 通过 `@antv/g2` 渲染。

- 入参：每条数据 `{ name: string, value: number }`。
- 渲染时机：组件挂载 + `component.data` / `component.type` / `component.props.color` / `filter?.code` 任一变化。
- 数据加工：先用绑定过滤器（前端 `Function` 沙箱）跑一次，错误降级到原数据，仅影响该组件。
- 销毁：组件卸载时 `chart.destroy()`，并断 `ResizeObserver`。

---

## 2. 数据契约

```ts
// 与 backend `data_set.data` JSONB 一致
type Datum = { name: string; value: number }
const data: Datum[] = [
  { name: 'Mon', value: 120 },
  { name: 'Tue', value: 200 },
  { name: 'Wed', value: 150 },
  { name: 'Thu', value: 80 },
  { name: 'Fri', value: 70 },
]
```

> v1 约定图表数据用 `name` / `value` 两个键。DB/API 返回的列名 ≠ 这两个键时，需用过滤器重命名（v1 字段映射后置）。

---

## 3. 通用初始化

```ts
import { Chart } from '@antv/g2'

const container = ref.current
const chart = new Chart({ container, autoFit: true })
let data = rawData
if (filter?.code) {
  const res = runFilter(filter.code, rawData)
  if (res.ok && res.data) data = res.data
}
chart.data(data)
chart.render()
const ro = new ResizeObserver(() => chart.forceFit())
ro.observe(container)
// 卸载：ro.disconnect(); chart.destroy()
```

## 4. 10 类图表写法

### 4.1 折线图（`line`）

```ts
chart.line()
  .encode('x', 'name').encode('y', 'value')
  .style('stroke', String(component.props.color ?? '#4f8cff'))
chart.point()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
```

### 4.2 柱状图（`bar`）

```ts
chart.interval()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
```

### 4.3 饼图（`pie`）

```ts
chart.coordinate({ type: 'theta', outerRadius: 0.8 })
chart.interval()
  .transform({ type: 'stackY' })
  .encode('y', 'value')
  .encode('color', 'name')
  .legend('color', false)
```

### 4.4 区域图（`area`）

```ts
chart.area()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
  .style('fillOpacity', 0.35)
chart.line()
  .encode('x', 'name').encode('y', 'value')
  .style('stroke', String(component.props.color ?? '#4f8cff'))
```

### 4.5 散点图（`scatter`）

```ts
chart.point()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
  .style('fillOpacity', 0.7)
```

### 4.6 雷达图（`radar`）

```ts
chart.coordinate({ type: 'polar' })
chart.area()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
  .style('fillOpacity', 0.25)
chart.line()
  .encode('x', 'name').encode('y', 'value')
  .style('stroke', String(component.props.color ?? '#4f8cff'))
chart.point()
  .encode('x', 'name').encode('y', 'value')
  .style('fill', String(component.props.color ?? '#4f8cff'))
```

### 4.7 漏斗图（`funnel`）

```ts
chart.interval()
  .encode('x', 'name').encode('y', 'value').encode('color', 'name')
  .transform({ type: 'symmetryY' })
  .style('fillOpacity', 0.8)
```

### 4.8 玫瑰图（`rose`）

```ts
chart.coordinate({ type: 'polar' })
chart.interval()
  .encode('x', 'name').encode('y', 'value').encode('color', 'name')
  .style('fillOpacity', 0.8)
```

### 4.9 文本/标题（`title` / `text`）

不走 G2，直接 div + 内联样式 + `{{var.xx}}` 变量插值：

```ts
const display = interpolateVars(String(component.props.text ?? component.name), variables)
```

## 5. 颜色约定

- 主题默认色 `#4f8cff`；画布背景 `#0b1020`；面板背景 `#151d2c`；网格 `rgba(255,255,255,0.06)` 20×20。
- 组件 `props.color` 决定主色；用户可在右侧样式面板覆盖。
- 套件（暮蓝/中性灰/紫色）v2 通过 `themeKit.apply(chart)` 切换，v1 仅改色。

---

## 6. 性能

- `Chart({ container, autoFit: true })`：G2 5 内部 ResizeObserver 自适配容器。
- 编辑器再叠加自己的 `ResizeObserver(() => chart.forceFit())`，用于 `fitMode` 变化时强制重算。
- 50 个图同时渲染：建议 `MIN=0.1, MAX=1.5` 缩放下保持 ≥ 30 FPS（实测看 `Editor.tsx` 顶部 FPS 计数器）。

---

## 7. 已知问题

- **`react-moveable` 0.56 警告** `componentWillUpdate`：G2 不直接受影响，但 v1 编辑器中拖动 Moveable 选区会触发 React 警告，下版本升级到 0.57+ 可消除。
- **G2 `autoFit` 与编辑器 padding 的耦合**：编辑时 `canvas-shell` 的 padding 变化会让 G2 重算尺寸，FPS 会出现一次抖动。ShareView 只读模式下不抖。
- **`bundle size` 警告**：G2 5 全量引入约 1.4MB gzip；v2 计划按 chart type 动态 import。
- **未走 `reactify`**：直接用 `new Chart()` 命令式 API，避免与 React 19 + StrictMode 双重挂载冲突。

---

## 8. 调试

- 浏览器 devtools → 选中 `canvas-stage` div → 看 `.g2` 子节点。
- 临时打开 G2 debug：`chart.emit('debug:show')`（需 G2 5.4+ 暴露该事件）。
- 编辑器右上角 `<FpsCounter />` 实时 FPS。

---

## 9. 迁移到 v2

- G2 6（如发布）会重做 theme/transform；届时通过 `g2Version` 字段在 `ComponentRenderer` 内做分支。
- 引入 `reactify` 包装器，让组件可以 `<G2Chart>` 直接渲染，配合 React 19 Suspense / streaming。
