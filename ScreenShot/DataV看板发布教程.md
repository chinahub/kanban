# DataV 看板发布与权限配置教程

本教程详细介绍 DataV 数据看板的发布流程，包括从控制台发布、生成分享链接、快照管理与回滚、访问限制配置以及加载页自定义等内容。

---

## 1. 看板搭建完成后的发布入口

看板搭建完成后，需要将看板发布后才能对外提供访问。DataV 提供两种发布入口：

- **控制台入口**：在工作台列表中直接发布
- **编辑页入口**：在大屏编辑页面右上角发布

![DataV 控制台工作台](attachments/images2/01_dashboard_list.png)

---

## 2. 从控制台发布看板

### 2.1 鼠标移入看板上

在 DataV 控制台"工作台"中，将鼠标移动到目标看板上方，看板右上角会出现快捷操作按钮：

![鼠标移入看板上](attachments/images2/02_hover_publish.png)

### 2.2 点击右上角"发布"图标

点击看板右上角中间位置的"发布"图标，弹出发布确认弹窗：

![点击发布图标](attachments/images2/03_publish_dialog.png)

### 2.3 确认发布

在弹窗中点击"发布大屏"按钮，系统开始执行发布操作：

![发布中](attachments/images2/04_publishing.png)

### 2.4 发布会自动生成分享链接

看板发布完成后，系统会自动生成一个分享链接，复制后即可在浏览器中访问：

![发布会自动生成分享链接](attachments/images2/05_published_link.png)

复制链接并粘贴到浏览器地址栏打开：

![复制链接在浏览器中打开](attachments/images2/06_copy_link.png)

访问效果：可以查看看板内容，所有图表、组件按预期展示。

---

## 3. 在编辑页发布看板

除了控制台，看板编辑页面右上角也提供"发布"按钮，可以一边编辑一边发布。

### 3.1 在编辑页右上方点击发布

进入看板编辑页面后，点击右上角的"发布"按钮：

![在编辑页右上方点击发布](attachments/images2/07_editor_publish.png)

### 3.2 在编辑页中发布看板

发布弹窗会在编辑页中弹出，与控制台入口相同：

![编辑页发布看板](attachments/images2/08_publish_config.png)

---

## 4. 快照管理

在发布配置中支持新增快照，也可在快照管理中配置快照，并且可以切换历史版本的快照内容。

### 4.1 新增快照

点击"自动新增快照并发布"按钮后，每次发布会自动保存一个快照：

![快照配置](attachments/images2/09_snapshot_config.png)

### 4.2 切换历史快照

发布历史中会列出所有的快照版本，下拉切换"发布日期"即可选择历史快照版本，并且可以切换历史版本的快照内容：

![历史快照版本](attachments/images2/10_snapshot_history.png)

### 4.3 快照管理入口

也可以在看板编辑页打开"快照管理"面板，对快照进行集中管理：

![快照管理](attachments/images2/11_snapshot_management.png)

### 4.4 新增快照

在快照管理面板中点击"新增快照"按钮，可以手动保存当前看板内容为一个快照：

![新增快照](attachments/images2/12_new_snapshot.png)

### 4.5 回滚快照

点击某条历史快照后的"回滚快照"操作，会弹出确认提示。回滚后当前内容无法恢复，如果当前内容为快照，确定要将该项目至指定快照吗？点击"确定"即可完成回滚：

![回滚快照确认](attachments/images2/13_rollback_confirm.png)

> ⚠️ 注意：回滚后当前未保存的内容会丢失，谨慎操作。

## 5. 访问限制配置

看板发布页支持 3 种访问限制方式：

1. **访问密码** — 通过密码访问
2. **通过 Token 验证** — 通过 URL 中的 token 参数验证身份
3. **IP 白名单** — 仅允许指定 IP 访问

### 5.1 启用访问限制

在发布弹窗的"访问限制"区域可以启用相应限制：

![访问限制](attachments/images2/14_access_restrictions.png)

### 5.2 访问密码

勾选"访问密码"后，可设置登录密码，支持以下规则：

- 密码必须为 6 位以上
- 至少包含一个大写字母 A ~ Z
- 至少包含一个小写字母 a ~ z
- 至少包含一个数字 0 ~ 9

### 5.3 通过 Token 验证

勾选"通过 Token 验证"后，访问者必须在 URL 中携带有效的 token 才能访问：

![Token 验证](attachments/images2/15_token_auth.png)

### 5.4 开启 IP 白名单

勾选"IP 白名单"后，可以在文本框中按行输入允许访问的 IP 地址。已添加的白名单 IP 才会被允许访问：

![IP 白名单](attachments/images2/16_ip_whitelist.png)

> 输入错误时系统会提示"请输入白名单列表"。

## 6. 看板描述信息

另外也支持自定义看板描述信息。

切换到"分享信息"标签，可以设置看板的标题、描述和图片。这些信息会展示在分享卡片和 SEO 场景中：

![看板描述信息](attachments/images2/17_dashboard_info.png)

配置项说明：

- **标题**：看板的对外展示名称
- **描述**：看板的简要说明
- **图片**：用于分享卡片展示的封面图，点击可上传 PNG/JPG 图片

---

## 7. 加载页设置

发布配置中"加载页设置"可以自定义看板在加载过程中的展示内容，包括背景和 Logo。

切换到"加载页设置"标签：

![加载页设置](attachments/images2/18_loading_page.png)

配置项说明：

- **背景**：上传加载页背景图片
- **Logo**：上传加载页显示的 Logo 图片（建议使用 PNG 透明背景）

---

## 8. 发布流程总结

完整的发布流程如下：

```
1. 控制台入口 或 编辑页入口 进入发布弹窗
   ↓
2. （可选）配置快照：新增 / 切换 / 回滚
   ↓
3. （可选）启用访问限制：密码 / Token / IP 白名单
   ↓
4. （可选）配置分享信息：标题 / 描述 / 图片
   ↓
5. （可选）配置加载页：背景 / Logo
   ↓
6. 点击"发布" → 自动生成分享链接
   ↓
7. 复制分享链接 → 浏览器中访问看板
```

---

## 9. 关键功能速查

| 功能 | 入口 | 用途 |
|------|------|------|
| 快速发布 | 控制台/编辑页发布按钮 | 一键发布并生成分享链接 |
| 快照新增 | 发布弹窗"自动新增快照并发布" | 自动保存历史版本 |
| 快照管理 | 编辑页"快照管理" | 集中管理所有快照 |
| 快照回滚 | 快照管理"回滚快照" | 一键回到历史版本 |
| 访问密码 | 访问限制 → 访问密码 | 简单的密码保护 |
| Token 验证 | 访问限制 → 通过 Token 验证 | URL 参数鉴权 |
| IP 白名单 | 访问限制 → IP 白名单 | 网络层访问控制 |
| 分享信息 | 分享信息标签 | 自定义分享卡片内容 |
| 加载页 | 加载页设置标签 | 自定义加载体验 |

> 💡 提示：发布前请确认看板内容已保存；启用访问限制后，分享链接需要附带对应凭证才能访问。
